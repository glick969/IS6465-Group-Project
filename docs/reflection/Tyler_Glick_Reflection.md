Ethics plays a large role in decision making when developing front end web pages. Starting first with deciding what the user is allowed to see and what the page should and should not ask the user to provide. For the login page an incorrect email or password input generates one generic error message, not revealing to the user whether an account exists or not. Another ethical decision involved in creating the login page was the inclusion of a 30 second timeout after 5 failed login attempts to discourage password brute forcing. The proper storage of user passwords in hashed form is also an important ethical concern when developing a login page. Our demo also clearly labels the account information as fictional, and discourages users from entering a real email or password.
Critical thinking was important when creating rules for the raw materials page. A simple quantity field would let anyone overwrite stock with no record of why it changed, so the quantity on hand can only be changed if a reason and the employee who made the change is included. This supports accountability and ensures that any changes have a valid reason for being made. The raw materials page also rejects any change that would put the stock of an item below zero, which would not make sense.
